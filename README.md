# MTR Tracker - 港铁实时监控与运行图系统

本项目是一个基于 Python (Flask 后端) 与前端拓扑可视化的港铁（MTR）实时列车运行监控系统。通过对官方 Next Train API 的高并发抓取、清洗以及精密的运行状态机推算，实现对港铁各线路列车停靠、区间车、站前/站后折返以及盲区轨道的实时监控。

---

## 🚇 三条核心线路逻辑总结

目前系统已深度适配并实装了三条市区核心线路，各自具有独特的拓扑与算法设计：

### 1. 荃湾线 (TWL)
* **核心基准**：作为项目的首条实现线路，确立了全套基础架构。
* **终点站校正**：针对中环 (CEN) 与荃湾 (TSW) 两端终点站进行方向与月台强制校正，防止因终点站信息变动导致方向误判。
* **过海段与时间校验**：针对金钟 (ADM) 与尖沙咀 (TST) 之间的关键过海段引入了 **>120秒的过海校验逻辑**，有效避免交叉地段的误判。
* **动态隔离**：采用复合 Key 剔除不稳定时间戳，确保离站检测与在途队列（`segment_queues`）的高效准确。

### 2. 观塘线 (KTL)
观塘线相较于荃湾线，引入了更为复杂的月台拓扑与折返盲区状态机：
* **黄埔站 (WHA) 站前折返**：因单正线月台限制（WHA1），采用 `ttnt < 3` 阈值精准捕捉折返与停站准备，双侧渲染同步、无残留。
* **彩虹站 (CHH) 三轨四月台西式布局**：正线常规车走 **CHH4 / CHH1**，中间 **CHH2/3** 专门处理折返车或出入九龙湾车厂车辆。
* **HOM 折返与蓝色盲区状态机**：针对何文田 (HOM) 无法直接追踪的折返盲区，设计了“**YMT触发 $\rightarrow$ 蓝区保持 $\rightarrow$ 红车覆盖 $\rightarrow$ 离站清除**”的严密时序状态机，完美解决盲区列车追踪难题。
* **调景岭 (TIK) 终端盲区**：终点折返段无法由 API 提供精准追踪，因此 **TIK1** 及其下行区段恒定显示为蓝色（不可追踪盲区）。

### 3. 港岛线 (ISL)
* **两端终点站优化**：坚尼地城 (KET) 与柴湾 (CHW) 两端终点站采用 **`ttnt <= 5`（轮次 n=5）** 作为开出与停靠判定。
* **站后折返适配**：针对 KET2 作为终点折返月台（站后折返无法直接跟踪）的情况，实行**蓝色标蓝**适配；KET1（往柴湾方向）则正常显示实时追踪状态。

## 🎨 界面与状态颜色说明

前端拓扑图采用状态色彩编码：
* **🔴 红色 (Red)**：常规全程车停靠月台，或在正线区段中运行。
* **🟢 绿色 (Green)**：区间车、折返车（非全线列车）停靠或在区段间移动。
* **🔵 蓝色 (Blue)**：不可追踪的配线盲区、站后折返段、或特定的区间折返占用。
* **车优先覆盖原则**：当蓝色盲区内有实际列车进站停靠时，红/绿列车状态会优先覆盖蓝色显示，车离开后蓝色自动回补。
